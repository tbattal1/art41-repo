# ART-41 — Vaka Kodlama: SANTOS (#18)
**Tarih:** 08.07.2026 | **Codebook:** v2.6 (K1–K16) | ✅ KİLİTLİ — 5/5 kaynaklı, sıfır MISSING
**Desen:** Federal SOE (CODESP) landlord + çoklu-özel operatör. **Dikkat: 2019 durumu (2022 özelleştirme/APS-dönüşümü öncesi).**

## YAPISAL ÖZET
- **Landlord:** CODESP (Companhia Docas do Estado de São Paulo) — federal empresa pública (1980); Lei 8.630/93 ile landlord modeli (operasyon özel terminallere devredildi, 1999 tamam). SEP-PR + ANTAQ regülatör altında. 2019 Ekim'de "Santos Port Authority" fantezi-adı; razão social değişimi 2020/2022 (pencere-sonrası).
- **Operatörler:** Santos Brasil (Tecon Santos — Latin Amerika'nın en büyüğü, kote), BTP (APM+MSC), DP World Santos (eski Embraport), Libra. Çoklu bağımsız özel.

## C1 = **0.30**
Özne = CODESP (federal SOE landlord, çoklu-operatöre kiralar, K9 2. dal). Tüzel kişilik (empresa pública) + kısmi tarife özerkliği (resoluções) AMA arrendamentos federal (licitação, União'ya döner), ANTAQ bağımsız regülatör, SEP-PR yönetir, politize board → stratejik+operasyonel kararlar ulusal sistem içinde → 0.30. **Kaynak:** pt.wikipedia CODESP (empresa pública federal, landlord); marineinsight (ANTAQ/SEP-PR).

## C2 = **0.95**
Konteyner >%80 özel + ≥2 bağımsız operatör (Santos Brasil/Tecon, BTP, DP World, Libra). **Kaynak:** en.wikipedia Santos Brasil (Tecon); DP World Santos.

## C3 = **0.50** (2/4)
C3.3=1 (600+ liman bağlantısı, uluslararası); C3.4=1 (**PAM — Plano de Ajuda Mútua**: CODESP'in liman-şirketleri arası kaza-önleme/müdahale koordinasyonu, liman-özgü çok-aktörlü); C3.1=0; C3.2=0 (ulusal sistem dikey). *Not: PAM'in "yasal-ötesi" niteliği coding-sheet'te işaretli.* **Kaynak:** pt.wikipedia (PAM).

## C4 = **0.33**
- C4a=0.33: Nova Lei dos Portos (Lei 12.815/2013) = pencere-içi yapısal reform.
- C4b=0.33 [Dal-A]: Brezilya arrendamentos 25-yıl; 1990'lar özelleştirmesinden çoğu 2020-2025 dolumu (Tecon 1997→2022; Terminal 39→2025); ağırlıklı ~10-15yr → 10-25 bandı → 0.33.
- C4c=0.33: Santos grev-eğilimli ("Red Port," güçlü sendikalar, "grev tüm şehri etkiler"); 2015-2019 Brezilya liman grevleri (2017 genel grev + özelleştirme-karşıtı) → ≥1 küme.
- mean(0.33, 0.33, 0.33) = **0.33**. **Kaynak:** en.wikipedia (Nova Lei; Red Port strikes); LCA (Terminal 39→2025).
