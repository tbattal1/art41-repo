## YAPISAL ÖZET
- **Operatör:** SIPG (Shanghai International Port (Group) Co., Ltd.) — Şangay Limanı'nın tüm kamu terminallerinin **tek (exclusive) operatörü**, çoğunluğu devlet.
- **Kronoloji:** Ocak 2003 Şangay Liman İdaresi'nden yeniden yapılandırma → Haziran 2005 hisseli şirket → 26 Ekim 2006 Şangay Borsası kotasyonu (Çin'in ilk kote liman operatörü, 600018.SH).
- **Mülkiyet:** Şangay SASAC ~%44 nihai kontrol; devlet-bağlı toplam >%70 (Shanghai State-Owned Capital Investment %28.3, Ya Ji/China Merchants-bağlantılı %28.1, COSCO Shipping %15.6).
- **Regülatör:** Şangay Belediye Ulaştırma Komisyonu / liman idaresi (SIPG'den ayrı idari işlev).

## C1 — REGULATORY AUTONOMY = **0.30**
- **Özne (K9):** Municipal port administration / devlet. SIPG exclusive operatör, üçüncü tarafa kiralamıyor → tek-operatör dalı → özne kamu tarafı.
- **Kanıt:** SIPG korporatize + kote (tüzel kişilik + operasyonel ticari özerklik) AMA çoğunluk devlet (SASAC ~%44), SASAC-atamalı liderlik, parti komitesi gözetimi, stratejik yön municipal/ulusal hedeflere bağlı.
- **Kontrol tipolojisi:** (i) hiyerarşik devlet vesayeti — Singapur'un profesyonel statutory board'undan (0.50) **daha derin** (liderlik ataması + parti gözetimi).
- **Kademe:** Korporatize otorite var (0.05 elenir) ama stratejik+liderlik kararları devlet sistemi içinde → **0.30**.
- **K13 notu:** K10(ii) hissedar-relief uygulanmaz — SIPG landlord değil; ayrıca devlet kontrolü pasif genel-kurul hakkı değil, aktif hiyerarşik yön.
- **Kaynak:** Wikipedia/SIPG (exclusive operator, majority state-owned); PitchBook/pestel (SASAC ~%44, devlet-bağlı >%70); Grokipedia (parti/atama, yolsuzluk soruşturmaları devlet-atama örüntüsü).

## C2 — OWNERSHIP HYBRIDITY = **0.30**
- **Metrik:** Konteyner ~%100 tek devlet-kontrollü operatör (SIPG, exclusive). Kote float + yabancı-line JV minority + COSCO (%15.6, merkezi SOE) var ama devlet-bağlı >%70.
- **K13:** Korporatize yerli devlet mülkiyeti = kamu-dominant.
- **Kademe:** Kamu dominant + biçimsel/kote yapı + minority özel katılım → **0.30** (Durban/Singapur emsali).
- **Kaynak:** yukarıdaki mülkiyet kaynakları.

## C3 — MULTI-LEVEL COORDINATION DENSITY = **0.50** (2/4)
1. **Kent–liman organı = 0.** SIPG municipal mülkiyet altında; ayrı kent-liman koordinasyon organı değil, sahiplik hiyerarşisi (v2 dikey-hiyerarşi dışlaması).
2. **Ulusal/bölgesel koordinasyon = 1.** Yangtze River Delta liman entegrasyonu (Aralık 2019 ulusal entegrasyon Outline'ı; SIPG'nin bölgesel liman iş birliği/çapraz-katılımı) + Shanghai Uluslararası Denizcilik Merkezi ulusal stratejisi. [Kanıt-temelli; coding-sheet'te SIPG'nin YRD çapraz-katılım spesifiği notlanır.]
3. **Uluslararası ağ aktif = 1.** Haifa Bay Terminal imtiyazı (2015); Barcelona/Avrupa/Avustralya green-digital corridor'ları.
4. **Liman-özgü kriz protokolü (yasal-ötesi) = 0.** FERM-muadili bulunamadı; ISPS evrensel (K11).
- **Kaynak:** SIPG kurumsal; YRD ulusal Outline (2019); imtiyaz/corridor kaynakları.

## C4 — COMPOUND LOCK-IN = **0.11**
- **(a) Düzenleyici katılık = 0.33.** 2005–2019 penceresinde 1 büyük yapısal reform: 2005 hisseli-şirket dönüşümü + 2006 kotasyon (ilk kote Çin liman operatörü). Yangshan (2005) altyapı, sayılmaz.
- **(b) Finansal kilit = 0.** Dal-B (devlet-operatör): net kâr ¥14.95B, dev capex, dünyanın en büyük otomatik terminali (Yangshan). 0/3 gösterge.
- **(c) Sosyal meşruiyet açığı = 0.** 2015–2019 operasyonel-etkili ihtilaf yok (kontrollü emek rejimi). Yolsuzluk soruşturmaları 2023 (pencere-dışı) + operasyonu kesmedi.
- **Ortalama:** mean(0.33, 0, 0) = **0.11**.
- **Not (Singapur kontrastı):** Şangay pencere-içi reform yaptı (0.33) → Singapur'dan (0.33 C4a, reform yok) daha düşük kilit; ikisi "korporatize-devlet" kümesinde C1+C4'te ayrışıyor.

## C5 — SOCIAL VALUE INTEGRATION = **0.40** (1/3)
1. **Bağlayıcı çevre/topluluk mandatı (kuruluş statüsünde) = 0.** SIPG tüzüğünde açık bağlayıcı çevre mandatı bulunamadı.
2. **Yönetişimde paydaş organı = 0.** Yasal PCC-tipi organ yok; parti komitesi paydaş-temsil organı değil.
3. **Bağlayıcı sosyal-yeşil koşul = 1 (K14).** Çin'in Yangtze River Delta Domestic ECA (DECA, 2016+) + zorunlu shore-power mandatı — bağlayıcı emisyon eşiği/shore-power (C5.3 örnekleriyle birebir). K14 (HOCAM onaylı 08.07.2026): evrensel bağlayıcı yeşil mandat sayılır.
- **Kaynak:** China DECA/YRD ECA düzenlemeleri; MOT shore-power mandatı.
